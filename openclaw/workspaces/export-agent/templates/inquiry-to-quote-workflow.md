**适用范围**: STA-100 自行车出口业务
**版本**: v0.1 (2026-08-17)
**Owner**: ExportAgent (export-agent)
**状态**: 模板初稿，待内部 review

---

## 0. 流程总览

| 阶段 | 输入 | 输出 | Owner | SLA |
|---|---|---|---|---|
| 1. 询盘登记 | 客户邮件/表单/通话 | RFQ 记录 + 客户匹配 | 销售 | 当日 T+0 |
| 2. 比价 | RFQ + 内部成本 + 物流报价 | 成本拆解 + 毛利测算 | 销售 + 采购 + 物流 | T+1~T+3 |
| 3. 起草报价 | 成本拆解 + 客户档案 | 报价单（PDF/DOCX） | 销售 | T+3~T+5 |
| 4. 跟进 | 报价单 + 客户反馈 | 结果闭环（成单/流失/重订） | 销售 | D+3 / D+7 / D+14 |

**触发**: 任何来自客户的有效询盘（含口头但需邮件补确认）。
**退出**: 客户接受→转 PO / 明确拒绝 / 报价到期未回（默认流失）。

### 1.2 客户匹配 & 历史回看
- 用 `客户编号` 调取历史订单、平均客单价、付款记录、退货率 —— **【GAP】当前未检索 orders 表，需后续调取本地**
- 新客户 → 触发《客户开户流程》（**【GAP】暂无模板**）

### 1.3 分类分流
- **标准品 + 老客户 + 现货** → 快速通道（可省略比价，套协议价）
- **标准品 + 新客户** → 完整流程
- **定制 / OEM** → 插入研发评估节点（**【GAP】需研发 SLA**）
- **战略客户**（如 Importer 大单或年度框架客户）→ 内部立项，P0

## 2. 比价（Cost Build-up）

### 2.1 成本拆解表（每 SKU 一行）

| 成本项 | 单价 | 单位 | 数据来源 | 当前状态 |
|---|---|---|---|---|
| 工厂出厂价（EXW） | ¥ | /台 | 采购部核价 | 【GAP】未取数 |
| 内贸运费（工厂→港口） | ¥ | /台 | 物流部 | 【GAP】 |
| 报关费 | ¥ | /票 | 货代 | 【GAP】 |
| 港杂（THC/文件/铅封） | ¥ | /票 | 货代 | 【GAP】 |
| 海运费（按柜型/航线） | $ | /CBM 或 /柜 | 货代即时报价 | 【GAP】需询价 |
| 海运保险（0.3%~0.5% CIF） | $ | /票 | 公式 | 标准 |
| 出口退税差额（如适用） | -¥ | /台 | 财务 | 【GAP】 |
| 汇率缓冲（建议 +1.5%） | $ | — | 财务 | 行业惯例 |
| **FOB 单价** | $ | /台 | 计算 | = EXW + 内贸 + 报关 + 港杂 + 退税差 |
| **CIF 单价** | $ | /台 | 计算 | = FOB + 海运 + 保险 |
| **DDP 单价（可选）** | $ | /台 | 计算 | = CIF + 进口关税 + 末端配送 |

### 2.2 毛利测算

```
销售价（外币）    : ____ USD
采购成本（人民币）: ____ CNY → 按当日中间价折算 USD
毛利率 = (销售价 - 折算成本 - 运费保险) / 销售价
```

- 毛利率警戒线：**【GAP】需内部财务口径**（建议参考历史均值 12%~18%）
- 低于警戒线 → 触发审批（销售经理 / 总经理）

### 2.3 比价策略
- 同一 SKU 至少取 2~3 家工厂报价（适用时）
- 备货 vs 现采 vs 期货取舍（**【GAP】当前无库存数据**）

```
       (Say: US Dollars One Hundred Seven Thousand Five Hundred Only)

```

### 3.2 报价单生成步骤
1. 复制模板 → 客户信息从 ACC 档案直接调入
2. 产品明细从 SKU 库填入（**【GAP】当前未连接 SKU 主数据**）
3. 选择贸易条款（默认 FOB，可选 CIF/DDP）
4. 设置有效期（行业惯例 30 天；欧洲客户可延至 45 天）
5. 选择付款方式（默认 30/70 T/T；战略客户可议价）
6. 内部审批（如需）
7. 转 PDF → 邮件发送 → 内部抄送归档

### 3.3 版本管理
- 每次修订生成新编号（QTN-2026-0817-001-R1, -R2 ...）
- 邮件正文附简短变更说明

## 4. 跟进（Follow-up）

### 4.1 跟进节奏

| 时点 | 动作 | 渠道 | 目的 |
|---|---|---|---|
| 报价发出 T+0 | 邮件发送 + 内部归档 | 邮件 | 留痕 |
| D+3 | 主动确认收到 + 答疑 | 邮件 / WhatsApp | 推动首轮反馈 |
| D+7 | 询问评估进展 + 补资料 | 邮件 / 电话 | 中期推进 |
| D+14 | 最后催复 + 表达诚意 | 邮件 | 收口或放空 |
| 报价到期 | 默认流失，归档原因 | 内部 | 数据沉淀 |

### 4.2 跟进登记表

| 字段 | 示例 |
|---|---|
| RFQ 编号 | RFQ-2026-0817-001 |
| 报价编号 | QTN-2026-0817-001 |
| 最近跟进日 | 2026-08-20 |
| 跟进人 | （销售） |
| 客户反馈 | "正在比另一家供应商，预计本周五给答复" |
| 异议点 | 价格偏高 3% |
| 下一步 | 提供 DDP 报价对比 / 申请阶梯价 |
| 预计成单概率 | 60% |
| 关闭条件 | 客户接受→转 PO / 明确拒绝 / 报价到期 |

### 4.3 异议处理脚本（常见 4 类）
1. **价格高** → 阶梯价 / 改付款条件 / 降配建议
2. **交期长** → 拆单分批 / 改柜型 / 空运溢价
3. **起订量高** → 同区域拼单 / 推荐近似小 SKU
4. **信任度** → 邀请验厂 / 同类客户参考（脱敏）/ 视频连线

## 6. 数据来源与缺口（重要）

### 6.1 本轮已确认可用的本地证据
- 当前模板不内置任何客户、订单、产品或私有文件样例。
- 实际运行时只能使用应用传入的本地证据、Agent 知识库证据和用户本轮输入，不得引用历史 demo 编号或示例客户。

### 6.2 当前未检索、需补充后才能跑通
- 订单 / 历史交易数据 → 比价阶段判断客户历史价
- 产品 SKU 主数据 → 报价单明细必需
- 工厂核价表 / 采购成本 → 比价核心输入
- 货代海运报价（按航线 / 柜型）→ CIF/DDP 报价必需
- 出口退税率 / 汇率中间价 → 财务口径
- 内部毛利率警戒线 / 审批层级 → 流程合规
- 客户私有知识库（如协议价 / 定制规格 / 年度框架）→ 本轮**未访问**，如已开通请授权
- 合规证书库（CE / EN 14764 / ISO 4210 有效期与适用产品）→ 报价附件必需

### 6.3 联网可补（如授权）
- 即期汇率、海运指数（CCFI / SCFI）、进口国关税税率

## 7. 使用说明

1. **首次落地**：把第 5 节分工补齐，把第 6.2 的 GAP 数据源逐项接入（建议接本地 `orders` / `skus` / `suppliers` / `freight_rates` 表）
2. **每次询盘**：复制 §1.1 的 RFQ 表，客户栏使用应用实际匹配到的客户档案
3. **每次报价**：复制 §3.1 报价单模板，替换抬头和明细
4. **每次跟进**：用 §4.2 登记表，每次联系都留痕
5. **月底复盘**：把 RFQ 编号、最终结果（成单 / 流失 / 重订）汇总到 CRM，沉淀转化漏斗

## 8. 工作示例（以客户询盘为例）

> 假设：客户来邮，询 500 台 26" 城市车 FOB Shanghai，10 月底前发货。

- 客户匹配 → 使用应用传入的客户档案；如未匹配到客户，则先进入新客户建档流程
- 分流 → 标准品 + 老客户 + 战略 → P0，内部立项
- 比价 → 工厂核价待补；CIF Gothenburg 海运需向货代询
- 报价 → 套 §3.1 模板，编号 QTN-2026-0817-001
- 跟进 → 按 D+3 / D+7 / D+14 节奏
